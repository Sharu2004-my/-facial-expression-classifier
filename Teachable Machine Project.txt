# Facial Expression Classifier – Teachable Machine

This is a basic machine learning project created using Google's Teachable Machine.

## 🧠 Description
This model classifies facial expressions into two categories: **Happy** and **Sad**. It was trained using webcam images.

## ⚙️ Tools Used
- Teachable Machine (TensorFlow.js backend)
- Webcam-based image input
- No-code training interface

## 🚀 How It Works
- Collected 30 samples for each class using the webcam
- Trained a model using Google's interface
- Tested the model on live webcam input
